### ABIs (for the frontend)

Generated by `forge build`:

- `out/WagerPoolFactory.sol/WagerPoolFactory.json`
- `out/WagerPool.sol/WagerPool.json`
- `out/MockUSDC.sol/MockUSDC.json`

Each JSON contains an `abi` array — that's what Sahitya imports.

### Frontend quick start

```js
import FactoryABI from './abis/WagerPoolFactory.json';
// create a pool (you become the host)
await factory.createPool(
  10_000_000n,  // buyIn: $10 (6 decimals)
  4,            // maxPlayers
  500           // feeBps: 5%
);
// then read the new pool's address:
const pool = await factory.pools(0);
```

Players then:
1. `usdc.approve(poolAddress, 10_000_000)` — on MockUSDC (call `mint()` freely for test money)
2. `pool.join()`
3. host: `pool.start()`
4. server: `pool.proposeResult(winner)`
5. anyone: `pool.finalize()` (after the 10-min dispute window)
6. winner: `pool.claim()`
